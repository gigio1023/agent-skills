# Documentation Style Anti-Patterns

Report or repair a pattern only when it harms the page in context.

## Buried Outcome

The command, decision, or supported behavior appears only after history or meta
commentary. Lead with the current outcome, then keep background that changes
interpretation.

## Mixed Reader Jobs

A page combines onboarding, exhaustive reference, architecture rationale, and
project status without a primary job. Move unrelated depth only when a maintained
destination exists and navigation can be updated safely.

## Bullet as Paragraph

One bullet holds several independent facts, conditions, and links. Split
parallel facts, add a genuine grouping parent, or return to prose when the ideas
form an argument.

## Decorative Structure

Tables, diagrams, callouts, or nested lists repeat simple prose without making a
comparison, sequence, hierarchy, or warning clearer. Keep the smallest surface
that communicates the relationship.

## Lost Condition

A brevity edit removes “when”, “may”, “optional”, a unit, or a version limit and
turns conditional behavior into an unconditional claim. Restore the condition
near the affected behavior.

## False Single Source

Essential context disappears from a standalone guide in favor of an inaccessible
or incomplete link. Deduplicate volatile detail, not the information required to
complete the page's job.

## Brittle Navigation

“Here”, a raw path in prose, or a renamed heading leaves the destination unclear
or breaks an inbound anchor. Use descriptive links and search references before
renaming headings.

## Meta Prose

Phrases such as “this section discusses” delay the claim. State the instruction,
decision, or reason directly unless the sentence establishes real scope.

## Unverified Example

A polished command or output looks authoritative but was copied, invented, or
not run. Verify it or label its status and placeholders explicitly.

## Style-Only Churn

A broad rewrite changes terminology and voice while fixing one local structure
problem. Constrain the diff and preserve intentional project vocabulary.
