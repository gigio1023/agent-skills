# 문서 품질 체크리스트

## 구조

- [ ] 정보 계층이 명확 (Tier 1~4)
- [ ] 문서 목적이 단일
- [ ] 링크 유효
- [ ] 중복 정보 없음 (참조 링크 활용)

## 내용

- [ ] 첫 문장에 핵심 포함
- [ ] 예시가 구체적이고 실행 가능
- [ ] 전문 용어에 설명/링크
- [ ] 모호한 표현 없음

## 스타일

- [ ] 한국어: 개조식 작성
- [ ] 표/리스트 중심
- [ ] 불필요한 배경 설명 최소화
- [ ] 용어 일관성 유지
- [ ] 이모지 사용 최소화

## 범위

- [ ] 작업 시간/소요 시간 미기재 (요청 시에만 포함)
- [ ] 장애 대응/담당자 호출 미기재 (Runbook 목적 문서만 예외)
