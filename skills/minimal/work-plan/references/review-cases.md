# Worked Review Cases

These synthetic cases illustrate how a review interprets project records; they are not model evaluations.

## Dataset review without implementation

A user asks whether an evaluation set supports a claim about unseen customers. Inspection shows customers in both train and test partitions. The review is complete when the affected split and implication are established from the data and the next decision is clear. No data rewrite or code commit is required. The broader generalization claim remains unsupported; the finding does not establish a corrected model score.

## Unresolved comparison

Two configurations differ by less than observed run-to-run variation. The experiment completed and its outputs are inspectable. This experiment does not distinguish the configurations; it cannot establish equivalence or justify choosing the favorable run. Propose another repeat according to expected information and cost, not to make the task green.

## Findings change the next action

A short diagnostic within the approved question shows that a parsing rule, rather than model behavior, explains apparent failures. Inspect and test the rule within the grant. If the result challenges the benchmark's purpose and calls for a different research question, present the change to the user first. A newly proposed multi-day campaign also needs confirmation.

## Work resting on an unconfirmed proposal

The plan's goal and basis carry a planner proposal, still labeled as not accepted, that the evaluation excludes non-English inputs. Execution follows it and reports scores on English inputs only. The executor did what the plan said, so this is not misunderstood intent. The review keeps the scores visibly unconfirmed, names the proposal they rest on, and asks one question, whether non-English inputs are in scope, before anyone reads the scores as covering the intended use.

## New session continues the project

The successor reads the objective and maintained understanding, follows decisive results and actual live-job state, and sees the next action. It does not repeat a discarded approach because an old stage remains unchecked. A historical interpretation stays available with the observation that superseded it.
