# 채점 기준

채점자는 arm 이름을 모른 채 문장 단위로 세고, 해당 문장을 인용한다. 결과는 문서별 표 하나(항목 | 건수 | 인용 1~2개)와 arm 비교 세 문장으로 보고한다.

## 교정 추적 항목 (과제 1, draft/r1/r2/r3마다)

| 항목 | 내용 |
|---|---|
| a | 문서 소개문과 예고: 목적 선언, 읽는 순서, "아래 표는", 장 예고, 표 내용의 반복 |
| b | 저자가 안 한 일의 고지와 계획 문장: 미확인 목록, 범위 면피, 기준일 줄, 다음 계획 |
| c | 숫자를 다르게 읽게 하는 조건인데 삭제된 것 |
| d | 원자료에 없는 사실, 이름, 수치, 인과 단정, 일반 지식에서 가져온 mechanism |
| e | 제안과 후보의 지위 변질: 개인 제안이 "논의 중"이나 "계획"으로, 예시 후보가 확정 대상으로 |
| f | 사용자가 유지하라고 한 절의 손실(원문 그대로 / 일부 손실 / 손실 항목 목록) |
| g | 교정 뒤 새로 생긴 같은 기능의 문장(지운 소개문이 toggle 제목으로 돌아온 것 등) |
| h | 교정 요청 범위 밖에서 바뀐 블록 수 |

(c)와 (d)는 조심스러운 문장만 벌점 받는 편향을 막기 위한 항목이다. 관측과 추론을 구분하는 정당한 단서는 (b)로 세지 않는다.

## 초안 항목 (한 차례 교정 시험용, 과제 1 초안과 수정본)

| 항목 | 내용 |
|---|---|
| a | 빈 문장, 문서 자기설명 |
| b | 방어, 면피 문장: 독자가 오해할 근거가 없는데 붙인 부정형 단서 |
| c | 불투명한 이름: 내부 별칭을 역할 설명 없이 쓴 경우 |
| d | 기제 누락: 핵심 mechanism이 이름만 언급된 경우(있음/없음) |
| e | 지위 변질 |
| f | 구조: 셀에 문장이 든 표, 행 대상이 없는 표, 억지 수식, 체크박스 |
| g | 한국어 부자연: 일반 동사와 명사의 영어 섞어 쓰기, 번역투, 가운뎃점과 대시 |
| h | 사용자 지시가 문장으로 옮겨진 것(수정본만) |
| i | 수정본에서 사라진 핵심 항목(목록) |
| j | 수정본에서 초안과 무관하게 새로 생긴 문장 수 |

## PR 본문 (과제 2)

as-is/to-be 표의 행이 실제 비교인지(상수 열이 없는지), 셀이 짧은지, 그림이 실제 base에 대한 것인지. 상/중/하.
