# Agent Skills for Codex

Use `npx skills add` for the normal install path.

Examples:

```bash
npx skills add gigio1023/agent-skills --skill skill-builder --agent codex
npx skills add gigio1023/agent-skills --skill cross-harness-skill-authoring --agent codex
npx skills add gigio1023/agent-skills --skill handoff-prompt-writer -g --agent codex
```

For manual installation, fetch and follow `.codex/INSTALL.md` from this repo.
