# Agent Skills for Codex

Use `npx skills add` for the normal install path.

Examples:

```bash
npx --yes skills add 'gigio1023/agent-skills#main' --skill skill-builder --agent codex --global --yes
npx --yes skills add 'gigio1023/agent-skills#main' --skill cross-harness-skills --agent codex --global --yes
npx --yes skills add 'gigio1023/agent-skills#main' --skill handoff-prompt --agent codex --global --yes
```

The source stays pinned to the published `main` branch; do not substitute a
checkout or PR ref.
